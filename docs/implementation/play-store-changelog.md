# Play Store Changelog

Play Store "What's new" notes are written by hand per release and per locale
in `distribution/whatsnew/<version>/`, checked in CI on the release-please PR,
and staged by `scripts/generate-whatsnew.sh` at publish time.

See [`distribution/whatsnew/README.md`](../../distribution/whatsnew/README.md)
for the flow, the checks and the writing guidelines.
